INTERVIEW DEMO PROJECT

Features:
1. Ride Booking
2. Vehicle selection (Bike, Auto, Car)
3. Distance calculation (demo logic)
4. Price per km calculation
5. UPI QR payment option
6. Cash payment option
7. Booking confirmation

How to Run:

1 Install Visual Studio
2 Create New Project -> ASP.NET Web Application (.NET Framework)
3 Select MVC template
4 Copy Controllers, Models, Views folders from this zip
5 Run project using Ctrl + F5

Demo Flow:

Home -> Book Ride -> Calculate Price -> Payment -> Confirmation
